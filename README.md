One haiku about debugging, in the 5-7-5 syllable shape, written by
`main.py` to `/output/entry.txt`:

> Cursor blinks at three
> the log line stops mid-sentence
> and I am the bug

The program is self-contained and deterministic: it writes the same
fixed text on every run. Run it with `python3 main.py`.
